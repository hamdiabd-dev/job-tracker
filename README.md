# Job Tracker

A personal job application tracker built to monitor my own job search.

## Goal

Track job applications through their lifecycle: sent → waiting → interview → offer/rejected. Provide reminders for follow-ups and analytics on response rates.

## Stack

- **Backend:** Python 3.11, FastAPI, SQLAlchemy, PostgreSQL
- **Frontend:** React, Vite, Tailwind CSS
- **Infrastructure:** Docker, Docker Compose
- **Deployment:** Railway (backend + DB), Vercel (frontend)

## Status

🚧 In development — building the MVP.
